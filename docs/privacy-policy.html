Privacy Policy — Whipped Extension

Last updated: June 8, 2026

Summary

The Whipped extension does not collect, store, transmit, or share any personal data or browsing data. It has no server connection of any kind.

Data collected

None. The extension does not collect any data.

How the extension works

When you click the toolbar icon, the extension injects a small script into the active tab so you can select a UI element. The selected element's component name, source file path, and DOM context are assembled into a text block and placed on your clipboard. This all happens locally in your browser.

The extension does not:

  • Send any data to any server
  • Store any data between sessions
  • Read page content except during an active select session you trigger
  • Track your browsing history or the pages you visit
  • Use cookies or any persistent storage

Permissions used

  • activeTab — reads the active tab's DOM only during a select session you initiate by clicking the toolbar icon
  • scripting — injects the element inspector script into the active tab on demand
